# 🤖 Rule-Based AI Chatbot

## Project Overview
This project is a simple rule-based AI chatbot developed using Python as part of the **Decode Labs Artificial Intelligence Internship – Project 1**.

The chatbot interacts with users by responding to predefined inputs using conditional statements (`if`, `elif`, `else`) and runs continuously until the user exits the conversation.

## Features
- Greets users
- Responds to basic predefined questions
- Provides a help menu
- Handles exit commands
- Runs continuously using a loop
- Uses rule-based decision-making

## Technologies Used
- Python 3
- Visual Studio Code

## How to Run
1. Open the project folder in Visual Studio Code.
2. Open the `chatbot.py` file.
3. Run the program.
4. Start chatting with the bot.
5. Type `exit` to end the conversation.
